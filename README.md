# Автотесты: «Адресный фонд» → «Адреса проживающих», уровень «Район»

Тестовое задание. Стек: Python, pytest, Playwright, Allure. Паттерн Page Object Model.

## Что автоматизировано

| Автотест | Тест-кейс |
|---|---|
| `test_open_dialog_default_state` | TC-01: Открытие окна создания района, состояние полей |
| `test_empty_name_not_saved` | TC-02: Район с пустым названием создать нельзя |
| `test_name_validation` | TC-02: Валидация поля «Название района» |
| `test_name_spaces_only` | TC-02, шаг 2: название из пробелов (ожидаемо падает, BUG-02) |
| `test_create_district` | TC-04: Создание района |
| `test_edit_district` | TC-10: Редактирование района |
| `test_delete_district` | TC-12: Удаление района: отмена и подтверждение |

## Установка

```
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium
```

Скопировать `.env.example` в `.env` и указать пароль тестового пользователя.

## Запуск

```
python -m pytest            # без окна браузера
python -m pytest --headed   # с окном браузера
```

## Отчёт Allure

```
allure generate allure-results --single-file --clean -o allure-report
```

Готовый отчёт: `allure-report/index.html`.

## Особенности стенда, учтённые в тестах

- **Стенд общий для нескольких пользователей.** Тесты работают только со своими
  данными: создают районы с уникальным названием `Автотест <время>` и удаляют их
  в постусловии. Чужие записи не затрагиваются.
- **Перезагрузка страницы сбрасывает авторизацию.** Поэтому сохранение данных
  проверяется повторным открытием раздела, а не F5.
- **Список уровней под кнопкой «+» открывается нестабильно.** Открытие окна
  создания выполняется с повторными попытками.
- **Окно создания, закрытое без «Отмена», оставляет в таблице пустую строку.**
  Фикстура закрывает окно после каждого теста.
- - **С серверов GitHub стенд отвечает медленно и нестабильно.** Запуск в
  GitHub Actions настроен, но выполняется только вручную (вкладка Actions →
  UI tests → Run workflow). В CI упавшие тесты перезапускаются до двух раз,
  время ожидания проверок увеличено до 15 секунд. Локально тесты проходят
  стабильно.

## Найденные дефекты

- BUG-01: кнопка «Внести» активна при пустом обязательном поле сразу после открытия окна.
- BUG-02: поле «Название района» принимает значение из одних пробелов.
